Scope cascading reveal to the home page only; add globe hover tooltip

client/src/components/Reveal.jsx
    Route-aware via useLocation(): off the home page ("/"), renders its
    child immediately, fully visible, with no IntersectionObserver and
    no transition. On home, behaves exactly as before (fade/slide in on
    scroll, staggered via the `delay` prop). Scoped centrally here
    rather than touching every one of the ~24 pages that use <Reveal>.

client/src/components/Globe.jsx
    Wires up the countryQuickStats prop Home.jsx was already computing
    and passing down "for the hover tooltip" but that Globe never
    actually consumed. Hovering a country now shows its name, most
    recent ETTI score (year), and most recent GTBI score (year) - or
    "Data pending" per index when that country has no real (non-
    placeholder) data for it, matching the existing Data Pending
    convention used elsewhere.

    Implemented as a single plain HTML div (not an SVG element),
    repositioned via d3.pointer() on mouseenter/mousemove/mouseleave,
    rather than per-country DOM nodes - one shared tooltip is simpler
    to reason about and avoids the constant creation/teardown of ~200
    tooltip elements as the globe rotates and re-renders paths.
    pointer-events:none (see App.css) is the key piece: without it the
    tooltip box would itself intercept hover once the cursor drifted
    over it, blocking the transition to whatever country is next
    underneath the mouse.

client/src/styles/App.css
    - #globe-container gets position:relative, anchoring the tooltip's
      position:absolute coordinates to the globe box instead of the
      page.
    - New .globe-tooltip* rules: styled to match the globe's own dark
      ocean/space canvas (not the site's light page theme, since
      that's the surface it actually floats over), with swatch colors
      matching the existing ETTI/GTBI legend for visual consistency.
      Anchor position flips toward whichever side/corner has room so
      it never runs off the edge of the globe box near the rim.
