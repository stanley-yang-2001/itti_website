New: server/country_profiles_upload.py — the docx counterpart to globe_data.py, doing the same four-step pipeline:

Validate — parses the upload with the exact same logic country_profiles.extract.py uses; nothing on disk changes if it fails.
Archive — copies the raw upload into data_scripts/country_profiles_storage/, timestamped, as a permanent audit trail.
Rotate (version control) — whatever file currently has that kind's canonical name in data_scripts/country_profiles_source/ moves into that folder's old/ subfolder, timestamped, before the new upload takes its place under the canonical name. Nothing is ever deleted.
Regenerate — re-runs the extractor's own build_profiles() against both canonical source docs and overwrites server/data/country_profiles.json — the file GET /api/country-profiles actually serves. The in-memory cache is invalidated immediately after, so the change is live with no redeploy.
