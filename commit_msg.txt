.github/workflows/deploy-frontend.yml
    - Added "Install Playwright's Chromium" step (npx playwright
      install --with-deps chromium) right after npm ci, before the
      build. scripts/prerender.mjs launches a real headless Chromium
      during npm run build's postbuild hook, and Playwright's browser
      binaries are a separate download from the npm package - without
      this step, that hook fails with "Executable doesn't exist ..."
      and npm run build exits non-zero, failing this entire job.
      Confirmed the failure directly: a fresh checkout's build exits 1
      without this step. The prior comment in prerender.mjs referenced
      installing this via app.yaml's build_command, which doesn't
      exist - stale from before the frontend build moved to this
      workflow.
    - robots.txt and sitemap.xml now get the same no-cache treatment
      index.html already had: excluded from the main sync's 1-year
      immutable cache-control and uploaded separately with
      no-cache/must-revalidate. Unlike hashed JS/CSS assets, these two
      keep the same URL forever but their content is meant to change
      (new sitemap entries, new disallowed routes) - the CDN purge
      step doesn't help here since it only clears DigitalOcean's own
      cache, not a crawler's.
