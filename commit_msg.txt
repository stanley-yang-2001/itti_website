Donations (embedded Payment Element + admin view) and Country

Donations
- Switch /donate from a Stripe Checkout redirect to an embedded
  Payment Element: PaymentIntent created server-side
  (POST /api/donations/payment-intent), confirmed client-side via
  stripe.confirmPayment(), webhook + thank-you-page status check both
  funnel through the same idempotent finalize_succeeded_donation().
- New admin-only donations list (/admin/donations, GET /api/donations,
  GET /api/donations/lookup/<code>): searchable by name/email/
  confirmation code, filterable by status, lifetime totals summary.
- Donate button moved out of the collapsible nav-links list into the
  top-right auth cluster, so it's always visible as a CTA.
- Added server/.env.example and docs/DONATIONS_SETUP.md (Stripe keys,
  webhook, Apple Pay domain verification, SMTP email delivery,
  migrations, promoting an admin) plus a placeholder
  apple-developer-merchantid-domain-association file.

Country Profiles / Reports style unification
- Both pages were still on the old light theme; rewrote both on the
  same dark-theme tokens used elsewhere (Docs/About/Observatory), with
  matching Reveal scroll animations.
- Country Profiles: every country now shows at once (no more
  click-a-letter-to-filter) as expandable rows with a flag, an
  available/unavailable indicator dot, and an inline data overview or
  the shared "unavailable" message. The A-Z bar is now a jump-to-section
  nav rather than a filter.
- Extracted UnavailableMessage (page vs. inline variant) from the old
  Unavailable page; both Country Profiles and Reports now redirect to
  /unavailable specifically on a 400 response (new isBadRequest()
  helper), with a configurable back-link via query params.
- Added a numeric-to-alpha-2 country code mapping (countryAlpha2.js,
  generated via pycountry, verified against every code in
  country_data.json) and a CountryFlag component using flagcdn.com.
- Found and fixed a real bug while unifying: Reports/Profile's
  .btn/.btn-primary/.btn-secondary classes were referenced but never
  defined anywhere - added them as a proper sitewide utility in
  App.css.
