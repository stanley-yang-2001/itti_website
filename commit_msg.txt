Observatory: select-all-data option + box plot chart; fix globe data-pending bug

1. Fix: globe panel shows "Data Pending" for GTBI/ETTI until year
   changed. SidePanel.jsx's default-year useEffect only depended on
   country.iso, but Home.jsx sets `country` state synchronously on
   click while the actual record loads asynchronously via
   fetchCountry() - the effect fired against the stale/empty record
   from before the fetch resolved, locked in gtbiYear/ettiYear as
   null, and (keyed only on country.iso) never re-ran once the fetch
   caught up. Fixed by computing the effective year fresh on every
   render instead of relying on effect timing.

2. Observatory: "Select all data (GTBI + ETTI)" button in the data
   explorer toolbar, behind a confirmation modal.

3. Observatory: new "Box plot (vs. all countries)" chart type -
   hand-rolled SVG box plot (Q1-Q3, median, Tukey 1.5*IQR whiskers,
   outliers) built from every country with real data for the chosen
   indicator, with checked panels plotted as colored points against
   that distribution.

Verified with `vite build`, a live dev-server run, and direct
Node-level testing of the box plot quantile logic against real data.
