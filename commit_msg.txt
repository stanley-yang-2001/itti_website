Also fixes a crash on the Search Results page: Reveal.jsx calls
React.Children.only(children), which throws unless it receives exactly
one element. The first <Reveal> in SearchResults.jsx wrapped two
siblings (an <h1> and a <form>), triggering "React.Children.only
expected to receive a single React element child" any time /search
rendered. Wrapped both in a single <div> so Reveal only ever sees one
child; confirmed the page's CSS uses descendant selectors
(.search-results-content h1, .search-results-form), not direct-child
selectors, so the extra wrapper doesn't affect styling.
